# Capstone Project

The Agri Machinery Reservation System is a web-based platform that allows Magalang farmers to easily rent agricultural machinery such as tractors, tillers, and harvesters from equipment owners.  Farmers can create accounts, search and filter machines by type, availability, and location, view detailed listings with images and pricing, and book equipment using a calendar-based reservation system.  Owners can list and manage their machines, monitor reservations, and receive ratings and reviews, while an admin panel handles user verification, approvals, and overall system monitoring. The system is built with HTML, CSS, JavaScript, Node.js, and MySQL, and uses JWT-based authentication and SSL for secure access.

🚀 Features

👨‍🌾 Farmer & Owner Accounts with authentication

🕒 Real-time reservation system with calendar availability

📝 Machine listing with images, pricing, and details

⭐ Review & rating system (owner ↔ renter feedback)

🛠 Admin panel for approving users & monitoring reservations

🔐 Secure login using JWT

📁 Database integration with MySQL

**Note:** The project is currently about 80% complete. Core farmer and owner features are functional, but some administrator features are not yet finished.


## Setup
1. Clone the repo
2. Run `npm install`
3. Configure `.env` for database settings
4. Run `npm start`
